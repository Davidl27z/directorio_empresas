# directorio_empresas
trabajo de la universidad

## Características
- Directorio web de empresas con categorías
- Panel administrativo para gestión
- Autenticación de usuarios
- Búsqueda y filtrado
- **Optimización SEO básica** (meta tags, sitemap, robots.txt)
- **E-Commerce básico** (catálogo por empresa, carrito, pedidos sin pago)
- **Sistema de roles** (Cliente, Empresa, Admin)

## E-Commerce Implementado
- Cada empresa puede crear su catálogo de productos
- Carrito de compras funcional para usuarios anónimos
- Sistema de pedidos con login obligatorio
- Tres métodos de contacto: WhatsApp, teléfono+email, email
- Panel de gestión de pedidos para empresas

## Roles de Usuario
- **Cliente**: Explora, compra productos, hace pedidos
- **Empresa**: Gestiona empresas y productos, recibe pedidos
- **Admin**: Control total del sistema

Ver `DOCUMENTACION.md` para detalles completos.
